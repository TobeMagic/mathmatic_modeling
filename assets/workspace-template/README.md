# Contest workspace

This tree is **our** Huawei Cup run. The Skill and reference first-prize papers stay in the Skill repo (`ref-papers/`).

```text
plans/          STATE / PROJECT / CONTEXT / 方案 / 实验矩阵 / 执行切片
problem/        当届题面、附件、官方文件
research/       全题侦察、文献笔记
modeling/       假设、符号、基线说明
code/           自选语言的求解代码（无语言模板）
data/           raw（gitignore）/ processed
experiments/    configs/ + runs/<run_id>/
results/        ledger、tables、figures、exports
reports/        数据审计、baseline、验证
paper/          OUR sections / manuscript / submission
```

Numbers: `results/result-ledger.csv` → `plans/claim-evidence.md` → `paper/sections/`.
Reference papers: Skill repo only, filenames `{year}-{tier}-{team_id}-{title}.pdf`.
