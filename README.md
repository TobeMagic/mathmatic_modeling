## 做什么

一条流程覆盖建模 + 编程规范 + 论文/绘图风格（含 AI 路线图 prompt 骨架）。不分论文手/建模手入口。缺实验标 `not-run`，不填数。训练分不是官方分。

S0–S8 与人工门 G1–G7 见 `SKILL.md`。论文/图：`references/paper-style.md`、`references/figure-style.md`、`assets/figure-ai-prompts.md`。参考论文用法：`references/ref-paper-usage.md`。
