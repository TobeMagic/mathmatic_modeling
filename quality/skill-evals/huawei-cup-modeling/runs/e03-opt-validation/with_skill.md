# 调度题验证清单（实验设计）

26.9 只是**当前目标函数值**，还不是一等奖纹理。对照 2022-C 一等奖摘要：同一套模型要打第二附件，并和「全走 4 车道」这类笨策略比。

## 必须补的实验（结果留空，直到你们跑完）

| id | 做什么 | 为什么 | status |
|----|--------|--------|--------|
| E1 | 规则/贪心/FIFO/单车道 基线 | 没有对照的 26.9 没有信息量 | not-run |
| E2 | 约束违反计数 | 高分但不可行 = 零分建模 | not-run |
| E3 | 第二实例或附件 | 防过拟合这一条序列 | not-run |
| E4 | 时间帽、种子、种群；必要时 gap | 可复现 | not-run |
| E5 | 扰动到达间隔/返回概率 | 鲁棒性，不是再吹一句「算法高效」 | not-run |
| E6 | 失败情景（堵死返回道） | 局限要写 | not-run |

## 不要做的

- 不要发明评委权重，也不要把验证清单说成获奖充要条件。
- 不要把 26.9 改成「最优」。没有证明最优就写启发式解。
- 图不要只画一张「建立模型→求解→结果」。

## 论文里怎么写

一段话：设置 → 基线分数 → 主模型分数 → 可行性 → 第二实例。表比 3D 柱重要。
